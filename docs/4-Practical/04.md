## HIPE-2022 French dataset for the TP

The TP dataset is **HIPE-2022 v2.1 / HIPE-2020 / French**. Download the prepared train, development and test files from the [dataset folder and loading guide](https://github.com/EmanuelaBoros/ie-course/tree/main/data/hipe2020-fr).

The files retain exactly `TOKEN`, `NE-COARSE-LIT`, `NEL-LIT` and `MISC`, with original document metadata, OCR tokens and sentence markers. The folder also includes the two official masked test variants, attribution, license and reproducible preprocessing instructions.

**Notebook transition:** the notebook below currently uses synthetic examples and a small fictional knowledge base. The HIPE loading guide is ready; the notebook's full NER/NEL pipeline still needs adaptation to HIPE labels and Wikidata candidates.

## What you will build

Inspect a synthetic annotated dataset and fixed knowledge base; implement longest-match NER, exact-span scoring, candidate generation and contextual linking; compare with real generative-AI outputs; analyze errors and launch your group project.

Cells marked **YOUR TURN** are intentionally unfinished. Checks guide you as you complete them. The notebook includes all classroom data; no model download or paid API is required. The optional plot uses matplotlib. A free browser model can supply the AI responses; missing responses are never presented as measured results.

## Run locally

Use Python 3.10 or newer:

```bash
python -m pip install notebook matplotlib
jupyter notebook
```

Open `01-ner-nel-practical.ipynb` and work from top to bottom. Core exercises use only the standard library; matplotlib is optional. Save your own copy before editing in Colab.

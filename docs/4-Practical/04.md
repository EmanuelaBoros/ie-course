## Objectifs

Examiner les annotations, implémenter une reconnaissance par plus long segment, calculer les scores exacts, rechercher des candidats et utiliser le contexte pour choisir une entité. Comparer ensuite votre algorithme à une IA générative et expliquer les erreurs.

Les cellules **À VOUS DE JOUER** sont à compléter. Les vérifications guident votre travail sans fournir les solutions. Les consignes, commentaires, messages et prompts sont en français. Les textes synthétiques et descriptions de la base restent en anglais afin de conserver les indices et les vérifications de l’exercice.

## Données HIPE-2022

Les [fichiers préparés et leur guide de chargement](https://github.com/EmanuelaBoros/ie-course/tree/main/data/hipe2020-fr) proviennent de **HIPE-2022 v2.1, sous-corpus HIPE-2020, français**.

Ils conservent exactement `TOKEN`, `NE-COARSE-LIT`, `NEL-LIT` et `MISC`, ainsi que les métadonnées des documents, les tokens originaux et les marqueurs de phrases. Les partitions d’entraînement, de développement et de test sont accompagnées des deux variantes officielles de test masquées.

**État du notebook :** les exercices publiés utilisent encore un petit corpus synthétique et une base fictive. Le chargement des fichiers HIPE est documenté, mais la chaîne complète doit encore être adaptée aux étiquettes HIPE et aux candidats Wikidata. Ne remplacez pas directement les données du notebook sans cette conversion.

## Organisation des trois heures

| Durée | Travail |
|---|---|
| 0–30 min | Comprendre les annotations et la base de connaissances |
| 30–75 min | Implémenter la NER et l’évaluation exacte |
| 75–120 min | Implémenter les candidats et le classement contextuel |
| 120–155 min | Recueillir les réponses d’une IA générative et figer les méthodes |
| 155–180 min | Évaluer, analyser trois erreurs et rédiger une conclusion |

Utilisez les mêmes données, ressources et mesures pour les deux approches. Conservez les réponses brutes de l’IA. Une réponse manquante n’est pas une prédiction vide. Si l’accès gratuit est indisponible, indiquez-le explicitement.

## Exécution

Dans Colab, enregistrez une copie personnelle avant de modifier le notebook. En local, utilisez Python 3.10 ou plus récent :

```bash
python -m pip install notebook matplotlib
jupyter notebook
```

Ouvrez `01-ner-nel-practical-fr.ipynb` et exécutez les cellules dans l’ordre. Les exercices de base utilisent la bibliothèque standard de Python. Le graphique facultatif utilise matplotlib. Un modèle accessible gratuitement dans un navigateur suffit pour la comparaison IA.

## Travail à rendre

- Le notebook complété, avec les réponses aux questions.
- Les prédictions, les prompts et les réponses brutes de l’IA, ou une explication de la difficulté d’accès.
- Les scores NER et NEL, accompagnés des effectifs évalués.
- Trois erreurs commentées et une courte conclusion sur les différences entre méthodes.
